# LinkFree

Plataforma de enlaces dinámica e interactiva para creadores de contenido, 
con encuestas, sorteos, rachas de interacción y gamificación.

## Estructura
- /backend → API en Node.js + Express + TypeScript
- /frontend → Interfaz en React + TypeScript

## Metodología
Este proyecto se desarrolla con Scrum, organizado en sprints.
